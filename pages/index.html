Busy Beaver Explorer

The bbchallenge project has sorted almost every six-state, two-symbol Turing machine into those that halt from a blank tape and those that never do. A few hundred holdouts are still open. This site covers two of them. Each is proved never to halt twice, once in Lean and once in Coq on top of busycoq. Each has a page that runs the machine in your browser and walks through the proof step by step, and a page that sorts every result by what it rests on.

bbchallenge machine #113,677

never haltsAlternates between long phases at the right end, which turn a run of 10 into a run of 1111110 or 1111011, and phases of round trips, which use that run up while runs of 1000 and 10 grow on the left. A table of phase rules is proved in Lean for all sizes, with a rule for every residue of the counts, and a linear invariant on the counts is restored by every rule; Lean and Coq (busycoq) both prove it never halts with the kernel alone.

bbchallenge machine #36,670

never haltsA list of counts written in stretches of 01: each round trip takes 3 from the first count while the rest of the list cycles through one of four periodic patterns, and when the first count runs out the second takes its place; Coq (busycoq) proves it never halts with the kernel alone, and Lean proves it too (kernel rounds, native_decide for the long runs).
